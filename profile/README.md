# Arcane Wizard

Arcane Wizard is a small group of hobby developers who enjoy creating World of Warcraft addons in their free time. Our projects grow from ideas we would like to use ourselves and from the simple joy of turning those ideas into useful tools for other players.

## Project Overview

| Addon | Description |
| :--- | :--- |
| **[Aurarium](https://github.com/arcane-wizard-dev/Aurarium)** | This addon keeps track of the wealth of all characters. It brings the recorded balances together and makes their development over time easier to follow. |
| **[Commodum](https://github.com/arcane-wizard-dev/Commodum)** | This addon simplifies everyday gameplay with optional quality-of-life improvements. It takes care of routine actions and allows parts of the interface to be adapted to personal preferences. |
| **[Expositum](https://github.com/arcane-wizard-dev/Expositum)** | This addon makes item tooltips more informative. It brings additional details into the tooltip, and their presentation can be customized. |
| **[Horatum](https://github.com/arcane-wizard-dev/Horatum)** | This addon keeps track of timing and results for supported boss encounters. Its display accompanies the current fight, and the results are saved for later reference. |
| **[Memento](https://github.com/arcane-wizard-dev/Memento)** | This addon preserves memories of adventures with automatic screenshots. It captures selected moments, and the capture process can be adapted to personal preferences. |
| **[Percursus](https://github.com/arcane-wizard-dev/Percursus)** | This addon tracks performance in supported races and makes it comparable, including Skyriding, Skyrocketing, and Breakneck (D.R.I.V.E.). It shows the progress live during a race and gathers times and targets in clear overviews. |
| **[Arcane&nbsp;Wizard:&nbsp;Library](https://github.com/arcane-wizard-dev/Library)** | This addon provides the shared base of all Arcane Wizard addons. It bundles the components they have in common, so each addon can focus on its own features. |
