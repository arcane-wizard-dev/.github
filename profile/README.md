# Arcane Wizard

Arcane Wizard is a small group of hobby developers who enjoy creating World of Warcraft addons in their free time. Our projects grow from ideas we would like to use ourselves and from the simple joy of turning those ideas into useful tools for other players.

## Project Overview

| Addon | Description |
| :--- | :--- |
| **[Aurarium](https://github.com/arcane-wizard-dev/Aurarium)** | This addon tracks gold and currencies across characters. It brings recorded balances together in clear overviews and makes changes over time easy to follow. |
| **[Commodum](https://github.com/arcane-wizard-dev/Commodum)** | This addon simplifies everyday gameplay with optional quality-of-life improvements. It handles routine tasks and lets you adjust parts of the interface to suit your preferences. |
| **[Expositum](https://github.com/arcane-wizard-dev/Expositum)** | This addon makes item tooltips more informative. You can choose which additional details appear and adjust how they are presented. |
| **[Horatum](https://github.com/arcane-wizard-dev/Horatum)** | This addon tracks the duration and results of supported boss encounters. A customizable timer shows the current fight’s duration, and the results are saved. |
| **[Memento](https://github.com/arcane-wizard-dev/Memento)** | This addon automatically takes screenshots of selected gameplay moments. You decide which events trigger a screenshot and how the screenshots are taken. |
| **[Percursus](https://github.com/arcane-wizard-dev/Percursus)** | This addon tracks times in supported races, including Skyriding, Skyrocketing, and Breakneck (D.R.I.V.E.). Follow your progress live during a race and compare race times and targets in clear overviews. |
| **[Arcane&nbsp;Wizard:&nbsp;Library](https://github.com/arcane-wizard-dev/Library)** | This addon provides the shared foundation for all Arcane Wizard addons. It brings common functionality together in one place, making it easier to develop and maintain the addons that use it. |
